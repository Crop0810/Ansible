# Below is a list of tools for servers and workstations using Ubuntu that we want to have installed

# ZSH
We want this for the basic shell that we can customise and make work with the style of usage we have. History will be a big one

# EZA
This improves the look and feel of the terminal by changing the icons and layouts and coloiurs

# Batcat
This organises the the text output from Cat to make it more coding friendly

# FD-Find
fd is a program to find entries in your filesystem. It is a simple, fast and user-friendly alternative to find. While it does not aim to support all of find's powerful functionality, it provides sensible (opinionated) defaults for a majority of use cases.

# FZF
fzf is a general-purpose command-line fuzzy finder and an interactive terminal toolkit.

# Ripgrep
ripgrep is a line-oriented search tool that recursively searches the current directory for a regex pattern. By default, ripgrep will respect gitignore rules and automatically skip hidden files/directories and binary files. (To disable all automatic filtering by default, use rg -uuu.) ripgrep has first class support on Windows, macOS and Linux, with binary downloads available for every release. ripgrep is similar to other popular search tools like The Silver Searcher, ack and grep.

# Starship
Theming for the ZSH Shell, requires nerd font

# Nerd Font
https://www.nerdfonts.com/ view the different fonts and select one for use on the terminals
